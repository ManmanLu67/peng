# 朋 · peng

把一句难懂的中文，降到学习者当前等级能读的说法。

## 使用

需要 Node.js 18 或更高版本。

```bash
cd web
npm start
```

打开 [http://localhost:5173/](http://localhost:5173/)。

首页点「开始」或鹊桥进入工作台。顶栏选择自己的 HSK 等级（1–6），输入一句中文：

- 句子比自己的等级更难时，降到自己这一档。
- 句子已经不高于自己的等级时，用明白的话重说，不再压低。
- 第一次结果是中文。点「没看懂」会再简单一档，可以一直降到英文。
- 「演示」用内置例句自动走完一遍。

没有配置模型时，示例句有现成结果；其他句子会标明是模拟数据。句子里的难词可以点开，查看拼音和释义。词表只覆盖演示用到的词。

## 接入自己的模型

把 `web/config/config.local.example.js` 复制为 `web/config/config.local.js`，填入接口地址、密钥和模型名。地址写到 `/v1` 为止。接口需要兼容 OpenAI 的对话接口，并允许从网页直接访问。

密钥和地址都填好后，刷新页面即可。密钥只留在本机，不会进入仓库。「演示」仍然使用内置例句。
