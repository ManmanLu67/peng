# 开发

改这个仓库时看这里。打开和使用见根目录 `README.md`。现在有什么、不做、约束见 `docs/agent/SCOPE.md`。做到哪一步见 `docs/agent/CURRENT_STATE.md`。

## 需要

- Node.js 18 或更新。在 `web/` 里执行 `npm start`，浏览器打开 [http://localhost:5173/](http://localhost:5173/)。页面运行时不引入依赖，这个命令直接提供 `web/src`。
- 检查：在 `web/` 里 `npm test`。完整检查是 `npm run verify`（依赖检查加测试）。
- 发布包：在 `web/` 里 `npm run build`，结果在 `web/dist/`。不把 `config.local.js` 打进包。
- 接入模型时，把 `web/config/config.local.example.js` 复制成同目录的 `config.local.js`，填入地址、密钥和模型名。没有这个文件时走 `web/data/demo.json`。
- 产品边界以代码和 `SCOPE.md` 为准。三页是 `#/` 首页、`#/app` 工作台、`#/team` 团队。首页入口是「进入」和双击小人。工作台在聊天栏选 HSK 起点（打开时是 HSK 3），右侧阶梯改当前这一句的档。

版本库里留着的说明只有这五份：`README.md`、`README.en.md`、`docs/开发.md`、`docs/agent/SCOPE.md`、`docs/agent/CURRENT_STATE.md`。英文版与中文版同一内容，以 `README.md` 为准。
