# 朋 · peng

把一句难懂的中文，改成你现在的水平能读懂的说法。

打开之后你会看到三页：

- **首页**：介绍这句话是怎么被改写的。点「开始」进入工作台。
- **工作台**：输入句子、看改写、点「没看懂」再降一档。
- **团队**：做这个网页的人。

顶栏可以在浅色和深色之间切换。选过一次后，这台电脑会记住。

## 打开

用浏览器打开下面任一网址：

- [https://peng-taupe.vercel.app](https://peng-taupe.vercel.app)
- [https://full-wren-d8g8nvxhy7c8cc8dd-1522218713.tcloudbaseapp.com/](https://full-wren-d8g8nvxhy7c8cc8dd-1522218713.tcloudbaseapp.com/)

两个网址是同一个网页。想在自己的电脑上运行，或接入自己的模型，需要先安装 [Node.js](https://nodejs.org/) 18 或更新的版本。装好后，在项目文件夹里打开终端，输入：

```bash
cd web
npm start
```

终端里出现本机地址后，用浏览器打开 [http://localhost:5173/](http://localhost:5173/)。关掉终端，本机上的网页就打不开了。上面两个网址不受影响。

## 工作台怎么用

1. 顶栏选出自己的 HSK 等级。HSK 是汉语水平考试的分级，1 最容易，6 最难。不确定就留在默认的 3。
2. 点输入框上方的一句示例，或者自己打一句中文，再点发送。
3. 左边是你的原话，右边是按你的等级改过的说法。句子里标出来的词可以点开，看拼音和意思。
4. 还是看不懂，就点「没看懂」。它会再简单一档。可以一直点，直到变成英文。到英文后就不能再降了。

改写时取「你的等级」和「这句话的难度」里更低的一档。句子比你的等级难，就降到你能读的程度。句子本来就不比你的等级难，就用明白的话重说一遍，不再故意压低。第一次给出的一定是中文，不会一上来就是英文。

「演示」会用内置例句自动走一遍：提交、连续点「没看懂」、直到英文。播放时先不要输入。演示结束，结果留在页面上。

三句示例都有现成的简化，其中「日照香炉生紫烟」下面会写着「语境 · 一个人对着水杯说」，表示这句话是在什么情况下说的。

## 没有接入模型时

上面两个网址，以及本机没有填入模型时，都是这样：示例句会按你选的等级给出简化。自己输入的其他句子会原样显示，右边写明没有改写。你输入的文字留在浏览器里。

## 接入自己的模型

上面两个网址没有填入个人模型。要接入，在自己电脑上按前面的步骤打开网页，再做下面三步。接入之后，自己输入的句子也会按等级改写。如果原文里写了场景、说话人或听话人，比如「一个人对着水杯说：这水太烫了」，这句话下面会出现一行语境。原文里没有这些信息，这一行就是空的。模型只摘原文里已经写明的那一段，不会另外编一个场景。

做法：

1. 把 `web/config/config.local.example.js` 复制成同目录下的 `config.local.js`。
2. 填入接口地址、密钥和模型名。地址写到 `/v1` 为止，例如 `https://api.example.com/v1`。
3. 保存后刷新页面。

接口需要能按 OpenAI 对话接口的方式接收请求，并且允许这个网页从浏览器直接访问。密钥只留在本机这个文件里。「演示」仍然使用内置例句，不把演示内容发给模型。
