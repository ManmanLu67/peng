# 朋 · peng

[English](README.en.md)

把一句难懂的中文，改成你现在的水平能读懂的说法。

打开之后你会看到三页：

- **首页**：介绍这句话是怎么被改写的。点「进入」进入工作台。
- **工作台**：和它对话。请它解释某一句时，右边才会改成更好懂的说法。点「没看懂」再降一档。
- **团队**：做这个网页的人。

顶栏可以在浅色和深色之间切换。选过一次后，这台电脑会记住。

## 打开

用浏览器打开下面任一网址：

- [https://peng-taupe.vercel.app](https://peng-taupe.vercel.app)
- [https://full-wren-d8g8nvxhy7c8cc8dd-1522218713.tcloudbaseapp.com/](https://full-wren-d8g8nvxhy7c8cc8dd-1522218713.tcloudbaseapp.com/)

两个网址是同一个网页。想在自己的电脑上运行，或接入自己的模型，需要先安装 [Node.js](https://nodejs.org/) 18 或更新的版本。装好后，在项目文件夹里打开终端，输入：

```bash
cd web
npm start
```

终端里出现本机地址后，用浏览器打开 [http://localhost:5173/](http://localhost:5173/)。关掉终端，本机上的网页就打不开了。上面两个网址不受影响。

要生成给发布用的压缩包，在 `web/` 里执行 `npm run build`。结果在 `web/dist/`，本机服务开着时打开 [http://localhost:5173/dist/](http://localhost:5173/dist/)。脚本和样式的文件名带内容哈希，可以长期缓存；页面和数据不缓存。密钥文件不会打进这个包。

## 工作台怎么用

1. 聊天栏右侧选出自己的 HSK 等级。HSK 是汉语水平考试的分级，1 最容易，6 最难。不确定就留在默认的 3。
2. 左上角可以在「降维翻译」和「聊天」之间切换。降维翻译会把你发出的句子简化到右边。聊天只在左边回复，不改右边。
3. 点输入框上方的一句示例，或者自己打一句话再发送。句子里标出来的词可以点开，看拼音和意思。
4. 还是看不懂，就点「没看懂」。它会把上一次解释的那句再简单一档。可以一直点，直到变成英文。到英文后就不能再降了。

降维翻译时，右边的原文就是你发出的那一句。原文下面先给出整句拼音，再列出典故、高出你当前等级的难词，以及语法拆解。接上模型后，任意句子里高出你等级的语法都会被拆出来；没接模型时，只有词表里对得上的语法。简化默认按你在聊天栏选的等级来写。第一次给出的一定是中文，不会一上来就是英文。右边的阶梯可以点：点哪一档，就把同一句改写成那一档，原文、语境和拼音保持不动。还没出结果，或正在处理时，阶梯不能点。再点「没看懂」时，这一句原文、语境和拼音也保持不动，只把说法再简化一档。

「演示」会用内置例句自动走一遍：提交、连续点「没看懂」、直到英文。播放时先不要输入。演示结束，结果留在页面上。

三句示例始终用内置的简化，不发给模型。其中「日照香炉生紫烟」下面会写着「语境 · 一个人对着水杯说」，表示这句话是在什么情况下说的。

## 没有接入模型时

上面两个网址，以及本机没有填入模型时，都是这样：降维翻译里，示例句会按你选的等级给出简化，其他句子原样出现在右边。切到聊天后，左边会回复「接上模型后才能对话」，右边保持空白或上一次的解释。你输入的文字留在浏览器里。

## 接入自己的模型

上面两个网址没有填入个人模型。要接入，在自己电脑上按前面的步骤打开网页，再做下面三步。接入之后，降维翻译会按等级改写到右边，聊天可以正常对话。如果句子开头用冒号写下了场景，比如「一个人对着水杯说：这水太烫了」，这句话下面会出现「语境 · 一个人对着水杯说」。没有这样的场景，这一行就是空的。三句示例和「演示」仍用内置结果。

做法：

1. 把 `web/config/config.local.example.js` 复制成同目录下的 `config.local.js`。
2. 填入接口地址、密钥和模型名。地址写到 `/v1` 为止，例如 `https://api.example.com/v1`。DeepSeek 写 `https://api.deepseek.com`，不要写控制台网址 `platform.deepseek.com`。
3. 保存后刷新页面。

接口需要能按 OpenAI 对话接口的方式接收请求，并且允许这个网页从浏览器直接访问。密钥只留在本机这个文件里。「演示」仍然使用内置例句，不把演示内容发给模型。
