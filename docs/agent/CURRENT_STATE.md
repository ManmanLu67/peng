# 当前状态

用法见根目录 `README.md`。边界见 `SCOPE.md`。本地目录和忽略规则见 `../开发.md`。

页面、深浅色切换、聊天 / 降维翻译切换和可选的模型接入都在代码里。首页是两张一样大的近正方形色纸（左芥黄、右南瓜橙）和中央深藏青小人。入口是「进入」和双击小人。左卡左下是 Original Text，右卡左下是 Adapted Text。工作台左侧对话，右侧是原文与改写。聊天栏右侧下拉选 HSK 起点，打开时是 HSK 3。右侧阶梯可点，换的是当前这一句的档。原文下有整句拼音、典故、难词和语法。

没有密钥时，降维翻译的示例句用 `demo.json`，其他句子原样显示；聊天只回复「接上模型后才能对话」。配好 `web/config/config.local.js` 后，降维翻译走模型，同一次请求带回原句拼音和最多 4 条语法点（记在消息上，换档不变），聊天也走模型。语法点与 `grammar.json` 里命中的合并，同名以词表为准。演示和三句示例仍走模拟。

词表是演示子集，释义未核对。团队成员的一句话和外链是空的，页面上不显示。

旧首页在 tag `home-v1`（`72037d6`）。`docs/archive/` 只留在本机。

界面上仍有中英并排的副标：色纸角标、对比栏标题、按钮译文、鹊桥节点上的中英两行。`SCOPE.md` 约束 7 要求版面不再重复说明，这一步还没做。

顶栏中间仍是 Workbench / Library / Archive / Team。Library 和 Archive 没有页面。
