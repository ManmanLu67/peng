## 首页（v2）

首页已按 `reference/主视觉.jpg` 重做：左下行人仰望，两岸的喜鹊（49 只）沿撕纸地层搭成的拱相向飞来，在拱顶相会，右山体是从拱顶长出的几条地层带。标题和「开始」在拱下空白。桥不再可点，入口只有「开始」。

- 旧首页（鹊桥 + 靛蓝大色块）已封存：`docs/archive/home-v1/`，git tag `home-v1`（指向 72037d6）。
- 构图数据在 `web/src/features/home-hero/composition.js`，拱和右山体都用 `core/geometry.js` 的 `ribbon()`。插画补色在 `web/styles/paper.css` 的 `.hero` 里局部声明。
- 首页纸色和墨色在 `.hero` 内固定，深色主题下也不变（黑鸟只有落在浅纸上才看得见），顶栏仍跟随主题。
- 横版（宽高比 ≥ 约 1.44）左下对齐铺满；竖屏和 4:3 平板取左侧（行人 + 拱的左半），标题放上方。

已验证：`npm run verify` 通过（依赖检查 + 147 项测试）；用 Edge 无头模式看过 2000×1180、1440×900、1024×768、420×860 四个尺寸。

没验证：Firefox / Safari；真机；窗口缩放时的实际滚动和帧率（纸张滤镜在新构图下的性能没实测，SCOPE 约束 6 要求实测前不改预渲染）；深色主题下首页只用系统强制深色截过一次图，没点主题开关。

已知差距：水彩晕染是色斑模拟，不是真水彩；拱与右山体仍是两个体块，靠拱压住带子起端来衔接；竖屏右下留白被裁掉；`reference/主视觉设计说明` 里「终点是右上天空、单向」与「相向而飞」自相矛盾，这版按相向做。

下一步：实测首页滤镜帧率；决定首页是否保留「桥可点」；`docs/archive/home-v1/` 是否要保留或只留 tag。

检查：在 `web/` 下执行 `npm test`；完整检查用 `npm run verify`。
