# 范围

以仓库里的代码和根目录 `README.md` 为准。`docs/brainstorm/` 是早期草案，不在版本库里，不作为需求。

## 现在有的

- 三页：`#/` 首页、`#/app` 工作台、`#/team` 团队。刷新停在当前页。三页顶栏中间都是 Workbench / Library / Archive / Team，后两项还没有页面。首页和团队页右侧是连接状态和深浅色开关，与工作台相同。首页是两张一样大的近正方形色纸（左芥黄、右南瓜橙）和中央深藏青小人。「进入」和双击小人去工作台。卡片本身没有悬停。Target Language 仍在右卡左下。右卡的鸟不可拖，只可点。静止鸟尖端朝上，没点开时在右下，右缘留出至少 6% 空白，点开后飞到 “T” 对卡片中心的对称点。深色是暖色夜纸，首页色纸、诗和小人另有一套夜色，不是把浅色底涂黑。点档位鸟后七只鸟不转圈，沿弧线落到角标上方、从第一个 “g” 排到右缘留出 6% 空白，不压住 Target Language；字等鸟落定后出现，并缩到这一页里。再点当前档或静止鸟则收起并复位。左右色纸可以在舞台里拖动，卡上的内容一起走。没有 i + 1。
- 团队页有句子或联系方式才显示。空白的不出现。
- 工作台：对话、示例句、原文与改写对比、HSK 起点、八级阶梯（可点）、四个流程节点（改写、没看懂、降档、结束）。
- 操作区两个按钮：「没看懂」降一档并走完 02、03 节点；「重试」只在请求失败后出现，重发上一次请求。可用性来自 `ladder.availability`：失败后只有「重试」可用，处理中和演示中全部不可用。
- 对比区内容超过一屏时可以用滚轮或触摸滚动，不显示滚动条。
- 「降维翻译 · Simplify」「聊天 · Chat」切换按钮中英并排，与页面其他文字一致。
- 工作台可以在「聊天」和「降维翻译」之间切换。聊天只更新左侧回复。降维翻译把这一句简化到右侧；之后换档不改原句、语境和拼音。
- 简化默认用聊天栏右侧下拉所选等级，打开时是 HSK 3，可选 HSK 1 到 6。点右边阶梯可跳到原文、HSK 6 到 1 或英文。处理中或还没有结果时不能点。「没看懂」仍是一次降一档，可以到英文。
- 默认用 `demo.json` 模拟。`web/config/config.local.js` 里同时有密钥和地址时，改走浏览器里的模型接口。演示按钮始终走模拟。
- 简化时，原文下面有整句拼音，以及典故、高出当前等级的难词、词表里对得上的语法。接上模型时，拼音和语法拆解由同一次简化请求返回；示例和没接模型时用词表拼音、`grammar.json` 的语法。换档不改拼音和语法。
- 顶栏可切换深浅色，选择记在本机；没有记录时跟随系统。

## 不做

语音、「还原」「更简单」「看懂了」按钮（含「读懂了」提示）、双栏连线、节点详情、错误详情面板、首页墨渍动画、学习记录、后端。

对应的命令或注释可以留在代码里，不为此建空页面。

## 约束

1. 页面只组合功能。功能之间不互相引用。改状态只经 commands。外部能力只经 ports。
2. 模拟数据放在 `web/data/`，不写进界面组件。
3. 不引入运行时依赖或构建工具。
4. 接口返回的文字用 `textContent`，不用 `innerHTML` 拼接。
5. 不提交密钥。`web/config/config.local.js` 保持在 `.gitignore`。
6. 首页纸张滤镜在实测卡顿之前不改成预渲染图。
